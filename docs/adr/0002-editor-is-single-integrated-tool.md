# Editor integrates authoring, image generation, and validation in one tool, one role

The Editor covers the whole Scene lifecycle — drawing the Scene Manifest/Source SVG, triggering realistic-image generation, and writing the Validation Report — used by a single Content Maintainer in one sitting. There is no separate QA/reviewer role and no split between an "authoring tool" and a "generation tool." This was chosen for simplicity at the current team size; splitting responsibilities (e.g. a separate reviewer role, or a separate generation pipeline) is a plausible future evolution once volume or team size grows, not the current design.
